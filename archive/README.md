# Historical material

`handoffs/` preserves historical proof ledgers and research ideas. Their constants
and status may be superseded; use the current workstream READMEs first.
`chvatal-scaffolding/` retains earlier Chvátal scaffolding.

`local/` contains gitignored workstation snapshots and scratch material. These
were moved rather than deleted because their unique changes have not all been
audited. None of this archive is part of a default proof build.
