# Limit existence and amplification research

This package retains conditional dyadic convergence and sorting-prefix
repair/locality arguments. It does not prove that `D(n)/log_2 n` converges.
The additive composition hypothesis in `ConditionalLimit` remains unproved.

It depends on the lower best package's construction-independent minimum-depth
foundations and comparator network model.

```sh
cd research/limit-existence
lake build AKS.Bounds.AmplificationAxioms
```

`scripts/` contains exploratory sorter amplification and repair probes.
See `../../docs/sorter-amplification.md` and `sorter-repair-barrier.md`.
