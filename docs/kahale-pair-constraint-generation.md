# A six-wire barrier for quadratic pair-mass corrections

## Certified result (2026-10-11)

The finite quadratic correction from the four/five-wire fit cannot be
replaced by another universal quadratic in the same ten mass coordinates.
Adding 2102 actual six-wire transitions makes the entire quadratic family
infeasible. An **exact rational Farkas certificate** verifies this, including
the constant term and all 65 linear/quadratic monomials.

This is a barrier for the specified correction family, not a barrier for
all pair-based potentials or a new sorting-depth lower bound.

Code: [constraint generation](../lower-bound/experiments/scripts/kahale_pair_constraint_generation.py).
Data: [self-contained certificates](kahale-pair-constraint-generation-results.json).
The script first needs the scratch base generated by
`python -B lower-bound/experiments/scripts/kahale_pair_correction.py`.

## Precise family ruled out

Retain the existing ten-term four-wire charge `Phi(R)`. On an `n`-wire prefix,
fix the first `n-4` outputs to zero and project the last four wires. Count
singleton/pair input preimages at projected masks
`1,2,3,4,5,6,8,9,10,12`, obtaining `c`.

Seek one polynomial `h(c)` of degree at most two, with arbitrary signed
coefficients, satisfying:

- `Phi(R)+h(c)` drops by at most 1 in every parallel layer;
- `h` is zero at the common initial profile;
- `h` is zero at globally sorted endpoints for four, five, and six inputs.

These requirements already contradict the finite set of actual prefixes.
The negative certificate does **not** require `h=0` whenever a projected
fiber becomes sorted while the global network remains unsorted. Removing
those additional local endpoint conditions still leaves an exact
contradiction.

The initial normalization preserves the previous potential's initial value
3. A redesigned base potential or a correction with different initial or
terminal values lies outside this result.

## Certificate and scope of checks

Use scaled correction `H=3h`. Each concrete layer gives an integer inequality
`(f(c)-f(c')) dot w <= 3-3Phi(R)+3Phi(R')`, where `f` lists the 66 monomials.
Endpoint conditions give homogeneous equalities.

The retained certificate has 67 weighted rows. Every layer weight is
nonnegative. Their left-hand sides, together with signed endpoint rows,
sum exactly to zero, while their right-hand sides sum to **-1**. Thus any
candidate would imply `0 <= -1`.

Every row is independently recomputed from its stored comparator prefix
on the complete input cube. The rational cancellation, right-hand-side
sum, and weight signs are checked exactly. The certificate is self-contained
in the result JSON; scratch signature indices are not needed to verify it.
This is Python exact arithmetic, not a Lean theorem.

The six-wire constraints come from 150 seeded trajectories with random
prefix layers followed by an odd-even sorting completion, plus the previous
explicit extrapolation failure. No exhaustive six-wire catalogue was built.
Exhaustiveness is unnecessary for the negative result: a finite set of valid
constraints suffices for a contradiction.

## What remains viable

An arbitrary correction table on the same mass profiles is still feasible
on all accumulated constraints, even with the stronger local sorted-fiber
endpoint conditions. Its 1109-profile rational certificate is checked and
stored. Therefore the obstruction is polynomial shape, rather than a proved
loss of information in the pair-mass summary.

The next useful test is a source-budget-normalized nonlinear correction,
using singleton and pair mass proportions and their overlaps. Require a
shared formula across budgets, test it against this exact obstruction,
and verify endpoint costs. Another unrestricted finite table alone would
not explain how to control overlapping scales.

The universal verified coefficient remains approximately 3.270559454.
