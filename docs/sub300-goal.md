# Sub-300 proof goal

Prove, with a complete checked construction,
`limsup_{n→∞} D(n)/log₂(n) < 300`, where `D(n)` is the minimum depth of a
binary-comparator sorting network on `n` wires.

At each restart, follow [`AGENTS.md`](../AGENTS.md) and the priorities and
working rules in [`sub300-work-plan.md`](sub300-work-plan.md). Start from
[`research-index.md`](research-index.md), then read the current route handoff
identified by that index/plan. Treat screens and estimates as leads, not proofs.
Preserve work in focused commits, keep generated artifacts out of source, and
report the strongest proved bound, the main open gap, and the next decisive step.
