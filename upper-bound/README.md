# Upper bounds

`best/` contains the current best kernel-checked upper bound in this repository:

```text
limsup D(n) / log₂ n ≤ 1770
```

It is a self-contained Lean package based on Chvátal's construction. See
[`best/README.md`](best/README.md) for the finite bound, proof map, and build instructions.

Exploratory upper-bound work is kept separately from this completed package.
