# Lower-bound workstream

`best/` contains the Kahale endpoint; `experiments/` preserves attempts to
improve it. Build each package from its own directory. The best real-valued
liminf proof uses a logarithmic upper bound from the retained legacy package
for boundedness; the finite Kahale inequality is independent of that bound.

See [best](best/README.md) and [experiments](experiments/README.md).
